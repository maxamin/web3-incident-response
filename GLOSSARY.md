# Glossary

- **War room:** dedicated channel and team coordinating an active incident.
- **Guardian:** narrowly scoped role (often a fast multisig) allowed to pause or restrict but not upgrade.
- **Circuit breaker:** on-chain limit that halts or caps activity automatically when thresholds are crossed.
- **SEAL 911:** Security Alliance emergency channel connecting teams with vetted responders.
- **Whitehat rescue:** using a vulnerability to move at-risk funds to safety before an attacker does.
- **Private mempool / bundle:** submitting transactions directly to builders so they are not publicly visible before inclusion.
- **Sweeper bot:** script that drains any funds arriving at a compromised address.
- **Holding statement:** first public message acknowledging an incident and giving user actions.
- **Fund tracing:** following stolen assets across addresses, protocols and chains.
- **Post-mortem:** structured, blameless report on cause, response and lessons.
- **Time to contain:** elapsed time from first malicious transaction to stopping further loss.
